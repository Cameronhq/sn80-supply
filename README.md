# SN80 (OpenRoboto) Alpha Token — Supply API

On-chain supply figures for the OpenRoboto subnet alpha token (Bittensor subnet 80),
updated hourly from chain data via TaoStats.

| Endpoint | Value |
|---|---|
| [`/totalcoins`](https://raw.githubusercontent.com/Cameronhq/sn80-supply/main/totalcoins) | Total supply (alpha staked by holders + protocol pool reserve) |
| [`/circulating`](https://raw.githubusercontent.com/Cameronhq/sn80-supply/main/circulating) | Circulating supply (alpha staked by public holders) |
| [`/maxsupply`](https://raw.githubusercontent.com/Cameronhq/sn80-supply/main/maxsupply) | Max supply (21,000,000 — Bittensor dTAO emission curve) |

Values are plain numeric text in whole alpha-token units (the denomination exchanges use for price).
